# The prompt with which I started this project

I want to create a native client app for google calendar for linux (and potentially windows and macos later).

The app should work just like google calendar web interface. The key feature that the app will offer is the ability to manage multiple google accounts in a
single calendar view. As far as I know, that is not possible with google calendar web interface. It is, however, possible with the google calendar android (and
possibly also ios) app.

In short, I want the user experience to feel just like google calendar web interface (the same UI, same keyboard shortcuts). But I want the ability to manage
multiple google accounts (e.g. personal and work account) just like in the android app.

The app should be feature-complete in comparison with the google calendar web interface.

The goal is that the app is fast and resource efficient - possibly it should be written in rust but I'm also open to other suggestions. I've never built a
desktop app before. Walk me through the process and follow best practices.
